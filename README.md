# Smart Password Generator 🔐

A Java-based Smart Password Generator that creates strong, secure, and customized passwords using user-specific information.

## 📌 Features

- Generate secure random passwords
- Password strength checker
- Customized password generation
- User-specific password creation using:
  - Name
  - PAN Number
  - Date of Birth
- Multiple user testing support
- Console-based interactive menu

## 🛠️ Technologies Used

- Java
- OOP Concepts
- VS Code
- Git & GitHub
